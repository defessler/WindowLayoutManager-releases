# Window Layout Manager — releases

Binary distribution for **Window Layout Manager**, a free portable
Windows app that saves and restores window layouts across monitor
setups. The source repo is private; this repo hosts only release zips.

- **Download page / docs:** https://dougfessler.com/projects/windowlayoutmanager/
- **Latest release:** https://github.com/defessler/WindowLayoutManager-releases/releases/latest

Install: download the zip from a release, extract anywhere, run
`WindowLayoutManager.exe`. The app self-updates from the feed at the
download page, verifying size + sha256 before installing.
